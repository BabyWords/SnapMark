# SnapMark

SnapMark 是一款使用 Swift、AppKit、ScreenCaptureKit 和 Vision 构建的原生 macOS 菜单栏截图工具。它支持截图、标注、OCR 文字选择、置顶预览、四方向长截图，以及无音频 MP4 录屏。

## 功能一览

### 截图与选区

- 从菜单栏选择“截图”，或使用全局截图快捷键启动；默认快捷键为 `⌘⇧X`，可在“设置快捷键…”中修改。
- 按住 `Shift` 拖动可创建正方形选区。选区可以移动，也可以拖动八个边缘/角点手柄调整大小；方向键可微调位置。
- 选区处理工具栏提供选择、箭头、矩形、椭圆、画笔、文字、马赛克和识别文字等工具，并可更改标注颜色。
- 按 `Esc` 或在截图界面按鼠标右键可取消当前截图操作。

### 标注、文字识别与撤销

- 通过箭头、矩形、椭圆、画笔、文字和马赛克标注截图；标注会合成到复制或保存的图片中。
- 点击“识别文字”进入 OCR 选择模式。SnapMark 使用 Apple Vision 的精确识别级别识别中英文；可拖选单个字符、行内片段或跨行内容，然后按 `⌘C` 复制。双击可选择全部识别文字；再次点击识别工具或选择其他工具可退出该模式。
- `⌘Z` 可撤销选区重选、移动、缩放、标注和文字输入等操作。

### 复制、保存与置顶

- 使用工具栏按钮将当前截图（含标注）复制到剪贴板，或保存为 PNG。
- “设置快捷键…”窗口同时提供保存位置设置。默认位置为“下载”文件夹；可选其他文件夹，也可恢复默认。截图、置顶图片保存和录屏共用该位置。
- 点击图钉按钮可将截图作为置顶悬浮图片显示，并结束当前截图处理。悬浮图可拖动；右键选择“保存”或“销毁”。

### 纵向与横向长截图

1. 框选可滚动内容区域。
2. 点击工具栏的纵向或横向长截图按钮。采集期间，选区边界会保持可见，目标应用仍可接收滚动输入。
3. 在选区内缓慢滚动。程序自动判断上/下或左/右方向，并根据相邻画面的重叠内容拼接；滚动过程中改变方向也会尝试继续拼接。
4. 再次按截图快捷键，或从菜单栏选择“停止长截图”结束。完成结果会以置顶预览显示，可右键保存或销毁。

长截图建议缓慢、连续滚动，避免快速跳过画面。对空白、重复或无法可靠匹配的帧，程序会保守跳过，以降低错误位移导致正文重复的风险；长图画布上限为 24,000,000 像素。

### 屏幕录制

- 打开菜单栏 SnapMark 菜单，选择“录制当前屏幕”开始录制鼠标所在显示器，或选择“选择区域录制…”框选录制范围；框选完成后自动开始录制。
- 录制期间会在录制区域显示红色范围边框，方便确认正在录制的范围。
- 录制输出为 H.264 编码的 MP4，**不采集音频**。文件保存到当前配置的保存位置，并使用带日期时间的文件名。
- 录制时菜单栏显示录制状态，且“录制当前屏幕 / 选择区域录制”会置灰；从菜单栏选择“停止录屏”正常结束并显示保存位置。录制过程中退出应用时会先结束录制。

## 设置与权限

- **设置入口**：菜单栏 SnapMark →“设置快捷键…”。可以录入新的全局截图快捷键，也可以修改保存文件夹或恢复“下载”文件夹。
- **快捷键要求**：自定义组合键必须包含 `⌘`、`⌥` 或 `⌃` 之一；如果快捷键已被系统或其他应用占用，SnapMark 会保留原设置并提示重试。
- **屏幕录制权限**：截图、长截图和录屏均需要 macOS 屏幕录制权限。首次使用时按提示前往“系统设置 → 隐私与安全性 → 屏幕录制”授权 SnapMark；也可以在菜单栏权限菜单项中打开设置。授权状态变化后，必要时按提示重新启动应用。

## 系统要求

- macOS 14 或更新版本
- Apple Silicon（当前构建目标为 `arm64`）
- Xcode Command Line Tools（提供 `swiftc`）

## 构建与运行

```bash
./build.sh
open build/SnapMark.app
```

构建脚本会优先使用本机名为 `SnapMark Signing` 的代码签名身份；若不存在则回退到 ad-hoc 签名。签名证书不包含在仓库中。首次启动时，macOS 可能会要求确认打开应用；屏幕捕获权限需由用户在系统设置中授予。

## 开发自检

```bash
./build.sh
./build/SnapMark.app/Contents/MacOS/SnapMark --selftest
```

自检涵盖演示图合成、纵向/横向四方向重叠匹配、滚动方向变化时的画布布局、白底文字小幅滚动与重复行歧义拒绝，以及录屏区域坐标换算。自检会输出演示 PNG 路径和尺寸。其他开发参数（如 `--demo`、`--capture-test`、`--cursor-probe`）仅用于本地排查，不属于面向用户的功能入口。

## 项目结构

```text
Sources/       Swift 应用源码（截图、覆盖层、标注、OCR、长截图、录屏等）
Resources/     应用图标
Info.plist     macOS 应用元数据与权限说明
build.sh       本机构建脚本
```

## 隐私说明

屏幕截图与录屏由 macOS 屏幕捕获 API 获取；文字识别通过 Apple Vision 在本机执行。项目没有配置将截图、录屏或 OCR 内容上传至远程服务的逻辑。
