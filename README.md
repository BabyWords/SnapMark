# SnapMark

SnapMark 是一款原生 macOS 菜单栏截图与标注工具，使用 Swift 和 AppKit 构建。可通过全局快捷键启动，框选屏幕区域后直接标注、识别文字、复制或保存。

## 功能

- **快速截图**：菜单栏入口与可自定义的全局快捷键；按住 Shift 可框选正方形区域。
- **选区调整**：移动选区、拖动八个边缘/角点手柄调整尺寸，方向键可微调位置。
- **截图标注**：箭头、矩形、椭圆、画笔、文字和马赛克；可选择标注颜色。
- **文字识别与选择**：基于 Apple Vision 识别中英文；可点击或拖选识别字符，包括行内部分文字和跨行文字，再用 `⌘C` 复制。识别按 Vision 的精确级别执行。
- **撤销**：`⌘Z` 撤销选区、移动、缩放、标注与文字输入等操作。
- **复制与保存**：将当前截图（含标注）复制到剪贴板，或保存为 PNG 到桌面。
- **取消操作**：按 `Esc` 或在截图界面按鼠标右键取消。
- **屏幕录制权限引导**：首次使用时提示开启 macOS 屏幕录制权限。

## 系统要求

- macOS 14 或更新版本
- Apple Silicon（当前构建目标为 `arm64`）
- Xcode Command Line Tools（提供 `swiftc`）

## 构建

```bash
./build.sh
open build/SnapMark.app
```

脚本使用 ad-hoc 签名，不需要个人证书或密钥。首次启动时，macOS 可能会要求用户手动确认打开应用；截图功能需要在“系统设置 → 隐私与安全性 → 屏幕录制”中授权 SnapMark。授权后若未生效，请重新启动应用。

## 开发自检

```bash
./build.sh
./build/SnapMark.app/Contents/MacOS/SnapMark --selftest
```

自检会输出生成的演示 PNG 路径和尺寸。其他开发参数（如 `--demo`、`--capture-test`、`--cursor-probe`）仅用于本地排查，不属于面向用户的功能入口。

## 项目结构

```text
Sources/       Swift 应用源码
Resources/     应用图标
Info.plist     macOS 应用元数据与权限说明
build.sh       本机构建脚本
```

## 隐私说明

屏幕截图由 macOS 屏幕捕获 API 获取；文字识别通过 Apple Vision 在本机执行。项目没有配置上传截图或 OCR 内容到远程服务的逻辑。
